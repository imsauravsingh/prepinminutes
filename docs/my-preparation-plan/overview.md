# My Preparation Plan — Overview

The **My Preparation Plan** module (`/preparation-plan`) provides software engineering candidates with an adaptive, milestone-driven curriculum mapped to their target role, interview deadline, and baseline skill competencies.

---

## 1. Module Objectives

1. **Eliminate Unfocused Preparation**: Structure preparation into sequential, achievable phases (e.g. Phase 1: Core System Design & Algorithms, Phase 2: Distributed Data & High Availability, Phase 3: Behavioral Leadership).
2. **Dynamic Adaptation**: Automatically re-weight study areas as candidates complete practice sessions and mock interviews. If a candidate struggles with Caching in a mock interview, the plan elevates Caching drills in the upcoming schedule.
3. **Readiness Alignment**: Display phase-by-phase readiness progress towards the candidate's target company hiring bar.

---

## 2. Key Personas & Phases

- **Senior Software Engineer**:
  - Phase 1: Core System Architecture & Trade-offs (Weeks 1–2)
  - Phase 2: Scalability, Caching & Data Partitioning (Weeks 3–4)
  - Phase 3: Behavioral Leadership (STAR Method) & Live Mocks (Weeks 5–6)
- **Time Commitment**:
  - Typically 8–12 hours per week, divided into 30–45 minute daily practice blocks.
